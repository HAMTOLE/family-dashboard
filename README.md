# Family Dashboard

거실 태블릿에 띄워 두는 가족용 1페이지 대시보드입니다. 빌드 과정 없이 `index.html` + `data.json` 두 파일로 동작하며, GitHub Pages로 배포됩니다.

디자인은 **GBA《포켓몬스터 파이어레드·리프그린》풍 픽셀 보드**입니다. 보드 전체가 포켓몬 마을 배경(`assets/gba-town-bg.png` — 트리·울타리·꽃밭·연못·집이 테두리를 두르고 가운데는 빈 잔디길) 위에 떠 있고, 여섯 카드는 게임 대화창처럼 **이중 픽셀 프레임**(짙은 남색 `#374B62` 3px 외곽선 + 안쪽 크림 `#FFFDF4` 띠 + 얇은 안쪽 선 + 4px 하드 그림자)에 크림 바탕(`#FFF8DF`)을 씁니다. 카드마다 상단 제목 바가 파스텔 게임 색(일정 민트 · 학교 하늘 · 책 연두 · 뉴스 라벤더 · 문제 파랑 · 캐릭터 핑크)이고, 완료/진행은 초록 `#77BD78`, 강조는 앰버 `#F2B85C`, 잔디는 `#9BD88A`입니다. 카드 사이 간격(12~18px)으로 마을 배경이 비치고, 카드 아래에는 도트 책더미·게시판·트레이너 장식이 붙습니다. 상단 왼쪽 HUD는 크림 바탕에 날짜·큰 도트 시계·`다크`·`전체` 버튼, 오른쪽은 하늘색(`#75A8D8`) 테두리 날씨 패널(몬스터볼 포인트 + 현재 날씨 + 7일 예보)입니다. 카드 헤더 아이콘·날씨·가족 아바타는 16×16 픽셀 SVG로 그렸고, 한글 본문은 Pretendard/시스템 고딕으로 읽기 쉽게 유지합니다. 다크 모드는 같은 마을에 밤 오버레이를 얹은 톤(짙은 남색 카드 + 어두운 파스텔 바)입니다.

## 화면 구성 (3 × 2 여섯 칸)

| | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| **윗줄** | 📅 일정 | 🏫 학교알림장 & 🍱 학교점심 | 📚 대출 중인 책 |
| **아랫줄** | 📰 어린이 뉴스 | ✏️ 오늘의 문제 | 👨‍👩‍👦 내 캐릭터 |

- **상단 HUD** — 왼쪽은 크림/민트 GBA 바에 오늘 날짜(도트 달력 아이콘)와 **큰 도트 디지털 시계**, 그 옆에 `🌙 다크`(밤 8시~아침 7시 자동)·`⛶ 전체` 버튼. 오른쪽은 **하늘색 픽셀 테두리 날씨 패널**로 몬스터볼 포인트 + 현재 기온·하늘/체감·최고/최저·바람 + 미세먼지 칩 + **7일 예보 한 줄** + 내일 주의 한 줄 + `11/18 10:45 업데이트`·­Weather 출처가 들어갑니다. 1024×768 태블릿과 1920×1080 모두 스크롤 없이 한 화면에 들어갑니다.
- **🧭 오른쪽 세로 도크** — 보드 오른쪽 끝의 폭 52~60px 세로 줄에 `📚 책장` · `🚀 은호` · `✏️ 학습` 세 버튼이 **게임 메뉴 버튼처럼 크림 박스 + 아이콘 + 작은 이름**으로 놓입니다(이름 색으로 구분: 책장 갈색 · 은호 초록 · 학습 주황). 누르면 **페이지를 옮기지 않고** 같은 화면 안에서 그 화면으로 바뀌므로 ⛶ 전체화면이 풀리지 않습니다. 좁은 화면(≤760px)에서는 도크가 보드 아래 가로 줄로 바뀝니다.
- **📅 일정** — `전체 / 아빠 / 엄마 / 은호` 필터를 누르면 그 사람 일정만 남습니다. 날짜·요일·오늘/내일 표시는 기기 시계로 계산합니다.
- **🏫 학교알림장 & 🍱 학교점심** — 위에는 오늘의 알림장 체크리스트(누르면 완료, 날이 바뀌거나 알림장이 새로 오면 체크가 새로 시작), 아래에는 오늘 급식 메뉴가 2열 칩으로 나오고 **메뉴 하나하나 옆에 `🤍/❤️` 하트 버튼**이 붙습니다. 오른쪽 `❤️ 모음` 버튼은 지금까지 모은 메뉴 개수를 함께 보여 줍니다.
- **❤️ 맛있었던 메뉴 모음** — 메뉴 칩을 누르면 그 메뉴만 `❤️`로 바뀌며 `{날짜, 요일, 메뉴, 분류, 시각}`으로 저장됩니다. `❤️ 모음`을 누르면 좋아한 메뉴가 날짜별로 모인 팝업이 열리고(메뉴마다 분류 배지 · `✕`로 그 메뉴만 삭제), 예전에 하루 급식 전체를 저장하던 형식도 메뉴별로 펼쳐 읽습니다. 급식을 확인하지 못한 날은 메뉴 칩이 나오지 않습니다.
- **📚 대출 중인 책** — 반납일까지 남은 날(D-day)을 크게, 그 아래 대출 중인 책 목록. 책 제목을 누르면 완독·별점·한 줄평 팝업이 열립니다. 책장은 오른쪽 도크의 `📚 책장` 버튼(또는 Esc·`← 오늘 보드`)으로 오갑니다.
- **📰 어린이 뉴스** — 기사 줄을 누르면 대표 사진·쉬운 설명·생각해 볼 질문·출처가 담긴 팝업이 열립니다(배경 클릭·✕·`확인`으로 닫힘). 국내 소식 · 과학·우주 소식 · 환경/어린이 시사까지 **하루 3건**. 카드 안에는 제목과 분류 배지만 있어 3×2 배치가 흔들리지 않습니다(3건이 1024×768에서 잘리지 않게 줄 간격을 맞춤).
- **✏️ 오늘의 문제** — 수학·과학·영어·국어를 고루 섞은 초등 5~6학년 문제 4개. 제목 옆 과목 배지가 붙고, 보기를 누르면 정답/해설이 나온 뒤 `다음 문제`로 넘어갑니다.
- **👨‍👩‍👦 내 캐릭터** — 캐릭터를 누르면 한마디 입력창이 열리고, 보낸 글이 아래 `가족 한마디 보드`에 보낸 사람과 함께 쌓입니다.

## 🚀 은호 공간 (`index.html#kids`)

은호가 안전하게 쓰는 공간입니다. **오른쪽 도크의 `🚀 은호` 버튼**(또는 주소 끝 `#kids`)으로 열리고, `← 오늘 보드`·Esc로 돌아옵니다. 책장과 마찬가지로 **페이지를 옮기지 않고 화면만 바뀌므로 ⛶ 전체화면이 풀리지 않습니다**. 1024×768 태블릿에서 스크롤 없이 한 화면에 들어가는 3단 구성입니다.

- **맨 윗줄 · 💰 저축 현황 · 목표/달성** — 카드 박스 없이 보드 위에 바로 놓인 스트립입니다. 왼쪽에 **핑크 돼지 저금통 + 금화 픽셀 SVG**가 서 있고, 목표 이름(누르면 수정), **모은 금액은 1.7~2rem으로 크게** 초록색으로, 그 옆에 `목표 금액`·`달성률 %`·`목표까지 N원 남았어요`가 붙습니다. 아래 게이지는 두껍게(14~18px) 깔리고 에메랄드(`#38B000`)로 채워집니다. `+1,000원` `+5,000원` `직접 입력`으로 모은 금액을 더하고, `목표 수정`에서 목표 이름·목표 금액·지금 모은 금액을 고칩니다. 목표를 100% 채우면 게이지가 금색으로 바뀌고 `🎉 목표 달성!`이 나옵니다. 기록은 이 브라우저의 `localStorage`(`familyBoard.savings.v1`)에만 저장됩니다.
- **가운데 줄 · 큰 아이콘 3개** — `📖 사전` / `⌨️ 타자` / `📐 과학·수학`. 카드 높이를 키우고 안쪽에 **16×16 픽셀 SVG를 72~96px로 크게** 그려(펼친 책 · 키보드 · 플라스크) 제목도 크게 잡았습니다. 누르면 그 기능만의 **넓은 전용 화면**이 열리고, 위쪽 `← 은호 공간`으로 홈에 돌아옵니다(`#kids-dict`·`#kids-type`·`#kids-math` 주소로도 바로 열립니다).
  - **📖 전자사전 (두 사전을 나란히)** — 검색창 위에 **`한글 낱말` / `영어 낱말`** 선택 버튼이 있고, 아무것도 고르지 않으면 낱말을 보고 자동으로 정합니다(같은 버튼을 다시 누르면 자동으로 돌아옴). 결과는 **두 칸**으로 나옵니다. **한글 낱말** → 왼쪽 `국어사전 뜻풀이`(한국어 위키낱말사전: 품사별 뜻·어원) + 오른쪽 `한영사전 · 영어로는`(위키낱말사전 번역어 + MyMemory 번역, 대표 단어 하나를 크게). **영어 낱말** → 왼쪽 `영한사전 · 한국어 뜻`(대표 한국어 뜻 + 뜻풀이) + 오른쪽 `영영사전 · 뜻과 예문`(쉬운 영어 위키낱말사전의 쉬운 뜻과 예문). 영어 낱말에는 **발음기호와 `🔊 발음 듣기`**(위키낱말사전 음성, 없으면 기기가 읽어 줌)가 붙고, 결과 속 단어를 누르면 그 단어를 바로 다시 찾습니다. 검색은 **사전 페이지로 넘어가지 않고** 결과 상자 안에서 끝납니다. 찾지 못하거나 인터넷이 막히면 칸마다 안내 문구를 띄웁니다. 최근 찾은 낱말 5개는 칩으로 남습니다.
  - **⌨️ 타자 미니게임 3종** — 위쪽 `🌧️ 낱말 비 막기` / `👾 낱말 배틀` / `💥 카드 슈팅` 탭으로 고르고, 오른쪽 `한글`·`English` 토글을 누르면 낱말이 통째로 바뀝니다(초등 어휘 · 동물 · 과학 · 사자성어 / 초등 영단어). 셋 다 광고 없는 내장 게임이고, **입력창은 무대와 점수판 사이에 크게(1.25~1.6rem·높이 56px)** 놓여 있으며 카드 아래에 **86px 이상 여백**을 두어 아이패드에 외장 키보드를 붙였을 때 뜨는 하단 단축·예측 바에 입력창이 가리지 않습니다. 입력창에 낱말을 **끝까지 정확히 치면 자동으로 맞으며**(Enter로도 되고, 틀린 글자는 빨갛게 흔들림) `점수 · 콤보 · 타수 · 최고 기록`이 아래 칸에 정리됩니다. 기록은 이 브라우저의 `localStorage`(`familyBoard.typingGameBest.v1`, 게임·언어별)에 남습니다. 낱말 배틀·카드 슈팅의 **기본 제한시간은 45초**입니다(낱말을 맞힐 때마다 게이지가 2초씩 다시 차고, Stage가 올라가면 배틀은 8초씩 짧아짐). 세 게임 모두 **Stage 1, 2, 3…** 로 이어지고, **Stage Clear마다 파트너 포켓몬 경험치 +10 XP**가 `familyBoard.study.v2`에 실제로 쌓여 100XP·250XP 진화로 이어집니다(아직 `미지의 알`이면 **알 부화 게이지**에 쌓임).
    - **🌧️ 낱말 비 막기** — GBA 비 오는 마을에서 낱말 블록이 빗방울을 달고 위에서 내려옵니다. 다 치면 낱말이 **톡 터지며 +10점**(콤보가 쌓이면 가산). 바닥에 닿으면 **하트(5개)** 가 하나 줄고 화면이 흔들리며, 다 잃으면 결과 판에서 `다시 도전!`. **낱말 10개마다 Stage Clear** — 다음 스테이지는 낙하가 빨라지고 낱말이 길고 어려워집니다.
    - **👾 포켓몬 낱말 배틀** — PokeAPI 도트 스프라이트 야생 포켓몬이 말풍선에 낱말을 들고 나타납니다(왼쪽 아래는 은호의 학습 공간 파트너 포켓몬 뒷모습). 정확히 치면 총알이 날아가 **HP 3칸이 한 칸씩** 줄고, 3개를 맞히면 **몬스터볼이 날아가 포획** — `잡았다!` 배너 뒤 다음 야생 친구가 등장합니다. **60초 제한시간**은 숫자 없이 위쪽 **시간 게이지 바**로만 보이고(초록 → 노랑 → 빨강), 낱말을 맞힐 때마다 게이지가 **+2초씩** 다시 차오릅니다. 0초가 되면 `⏰ 시간 끝!` 결과 판에 점수·잡은 친구 수·최고 기록이 나옵니다. **야생 친구 3마리마다 Stage Clear** — 다음 스테이지는 제한시간이 8초씩 짧아지고(최소 30초) 낱말이 어려워집니다.
    - **💥 낱말 카드 슈팅** — 왼쪽 픽셀 사수가 총을 들고, 오른쪽에 **3×3(9칸) 낱말 카드 보드**가 깔립니다. 9개 중 아무 낱말이나 치면 그 카드가 **노란 조준 표시**로 빛나고(친 글자는 초록), 낱말을 끝까지 치면 사수 총구에서 **총알이 그 카드를 향해 슝 — 펑!** 터집니다. **60초 타임어택**은 숫자 없이 위쪽 **시간 게이지 바**(초록 → 노랑 → 빨강)로 보이고, 카드를 깰 때마다 **+2초**씩 게이지가 다시 찹니다. 콤보·최고 기록이 붙고, **9칸을 다 깨면 Stage Clear — +30점 · 시간 +10초 · 새 9칸**. 스테이지가 올라갈수록 2글자 → 3글자 → 4글자·사자성어·긴 영단어로 어려워집니다.
  - **📐 수학·과학 도구** — `알지오매스 키즈`·`Mathigon 폴리패드`·`PhET 초등 과학`을 새 창으로 열고, 아래 네 칸에서 **분수 계산(약분·소수 표시)**, **단위 바꾸기(cm↔m↔km, g↔kg, mL↔L)**, **도형 넓이(직사각형·삼각형·원)**, **최대공약수·최소공배수**를 바로 계산해 봅니다.
- **맨 아랫줄 · 📺 추천 유튜브 영상** — 영상 목록은 `data.json`의 **`kidsVideos`**를 먼저 읽고(없으면 `index.html`의 같은 기본값) EBS 5개 시리즈(`지식채널e` · `역사채널e` · `3분 클립 과학` · `스쿨랜드 철학` · `헌법채널e`) 탭을 고르면 그 시리즈의 영상 2개가 **가로 2열 한 줄**로 콤팩트하게(썸네일 위 · 제목/소개 아래) 나옵니다. 이 영역 전체 높이는 1024×768에서 약 **280px**로 화면 높이의 절반(384px)보다 훨씬 작아, 위쪽 저축·아이콘 카드가 시원하게 보입니다. 카드를 누르면 `youtube-nocookie.com/embed/...?rel=0` 플레이어가 팝업으로 뜨고 **추천 영상·쇼츠·댓글 없는 화면**으로 재생됩니다. 영상이 안 열리는 환경을 위해 `▶ 유튜브에서 보기` 링크도 함께 둡니다.

## 📚 은호의 책장 (`index.html#shelf`)

`index.html` 안에 들어 있는 두 번째 화면입니다. 오른쪽 도크의 `📚 책장` 버튼으로 열고 `← 오늘 보드`(또는 Esc)로 돌아오며, 페이지 이동이 아니라 화면 전환이라서 태블릿 전체화면이 그대로 유지됩니다. `index.html#shelf` 로 바로 열 수도 있고, 예전 주소 `bookshelf.html` 로 들어와도 이 화면으로 넘어옵니다.

- **제목**: `📚 은호의 책장` — 엄마 책은 넣지 않고 **은호 책만** 보여 줍니다(사람별 필터 없음).
- **상단 카운터 2개**: `🏅 올해 완독`(권수·최근 완독한 책) 과 `📖 현재 대출 중`(권수·`D-13`·반납 예정일).
- **📅 연도별 책장 탭**: 카운터 아래 `📅 2026년` `올해` 탭이 있고, **완독 기록이 있는 해마다 탭이 저절로 생깁니다**(올해 탭은 완독 0권이어도 항상 표시). 지난해 탭을 누르면 그 해에 다 읽은 책만 모아 보여 주고 `🏅 2026년 완독 N권`처럼 카운터도 그 해 기준으로 바뀝니다. 해가 바뀌면(예: 2027년) 새해 탭이 기본으로 열립니다.
- **맨 윗선반**: 지금 연도 탭에서만 `📖 지금 대출 중` 선반이 나오고, 각 책에 `대출 중 · D-13` 리본이 붙습니다. 지난 연도 탭에서는 대출 선반 없이 그 해 완독 책만 나옵니다.
- **그 아래 선반부터**: **다 읽은(완독) 책만** 읽은 순서대로 쌓입니다. 아직 안 읽은 희망 도서·미대출 책은 꽂지 않고, 완독이 0권이면 `다 읽은 책이 여기에 한 권씩 채워져요!` 안내가 나옵니다. 이미 완독한 책의 별점·한 줄평을 고쳐도 그 책은 처음 완독한 해에 그대로 남습니다.
- 책을 누르면 `다 읽었어요! (완독)` + ⭐별점 + 한 줄평을 저장할 수 있고, 저장하면 그 책이 아래 완독 선반에 꽂히며 `🏅 올해 완독` 숫자가 바로 올라갑니다. 대출 중인 책을 완독해도 반납 전까지는 윗선반에 `대출 중` 리본과 함께 남고, 완독 배지(✓·★)가 같이 붙습니다(아래 선반에는 `대출 중` 표시가 작게 붙습니다).
- 기록은 `localStorage` 키 `familyBoard.bookReviews.v1` 하나를 메인 보드와 함께 씁니다. 저장할 때 책 제목·저자·표지도 같이 남겨서, `data.json` 목록에 없는 책이라도 완독 선반에 표시됩니다.

## data.json — 매일 아침 자동 갱신되는 데이터

화면에 보이는 값은 모두 `data.json` 하나에서 옵니다. 페이지를 열 때 `./data.json?t=<현재시각>`으로 매번 새로 받아 그리므로, `data.json`만 고쳐 올리면 화면이 바뀝니다.

```json
{
  "updatedAt": "2026-11-18T10:05:00+09:00",
  "weather": { "place": "용인 · 수지구", "tempC": 6, "feelsC": 2, "condition": "흐림",
               "highC": 10, "lowC": 2, "wind": "북서풍 12km/h",
               "air": [ { "label": "미세먼지 좋음", "grade": "good" } ],
               "alert": "내일 아침 -2° … 목도리 챙기세요." },
  "lunch":   { "status": "ok", "note": "세계음식체험 · 인도 / 572 kcal", "menus": ["찹쌀밥", "마크니커리"] },
  "events":  [ { "date": "2026-11-19", "time": "11:00", "title": "모두의 마당 모임", "place": "코엑스", "who": "mom" } ],
  "notices": [ { "id": "n1", "text": "수학 익힘책 38~39쪽 풀어 오기" } ],
  "news":    [ { "tag": "사회", "title": "제목", "body": "쉬운 설명",
               "question": "생각해 볼 질문", "image": "https://…/대표사진.jpg", "source": "출처 (날짜)" } ],
  "kidsVideos": [ { "name": "지식채널e", "channel": "EBS 지식채널e", "icon": "🧠",
                    "videos": [ { "id": "유튜브 영상 ID", "title": "제목", "desc": "한 줄 소개" } ] } ],
  "quizzes": [ { "subject": "수학", "q": "문제", "opts": ["①", "②", "③", "④"], "answer": 0, "why": "한 줄 해설" } ],
  "books":   { "due": "2026-12-01", "items": ["책 제목", "..."] },
  "shelfBooks": [ { "id": "b5b110e", "title": "책 제목", "author": "저자", "who": "kid",
                    "status": "loan", "statusLabel": "대출 중", "cover": "covers/b5b110e.jpg",
                    "doneYear": "", "due": "2026-12-01" } ]
}
```

- `shelfBooks` — 책장에 쓰는 은호 책 목록입니다. `who`가 `mom`인 책은 책장에 나오지 않습니다. `status`가 `loan`인 책이 올해 탭의 윗선반(대출 중)에 꽂히고, 나머지는 완독 기록이 있을 때만 아래 선반에 꽂힙니다. 대출 중 책의 반납일은 `books.due`를 먼저 씁니다. `doneYear`(노션 `완독일`, 예: `"2026"` 또는 `"2026-05-03"`)가 있으면 그 해 책장에 꽂히고, 비어 있으면 앱에서 완독을 누른 날의 해를 씁니다.

- `kidsVideos` — 은호 공간 맨 아래 추천 영상 5개 시리즈입니다. 매일 오전 6시 갱신 때 시리즈마다 1~2편이 전날과 겹치지 않는 새 EBS 영상으로 바뀌고, 각 시리즈는 늘 2편을 유지합니다. `videos[].id`는 유튜브 영상 ID입니다.
- `who`는 `dad` / `mom` / `kid` 중 하나입니다. `answer`는 정답 보기의 순번(0부터)입니다.
- `quizzes[].subject`는 `수학` / `과학` / `영어` / `국어` — 화면 제목 옆 배지로 나오고 문제마다 색이 다릅니다.
- `news[].image`는 기사 팝업에 뜨는 대표 사진 URL입니다. 사진이 안 열리면 그 사진만 조용히 숨고 글은 그대로 보입니다(팝업 안에서 최대 높이만 제한).
- `lunch.status`가 `"ok"`가 아니거나 `menus`가 비어 있으면 화면에 `오늘 급식 정보 미확인`이 나옵니다. 확인하지 못한 날은 메뉴를 지어내지 말고 이 상태로 두세요.
- `weather.condition`은 한국어(`흐림`, `맑음`, `약한 비` …)로 적으면 그대로, 영어(`Cloudy`, `Drizzle` …)로 적으면 화면에서 한국어로 바꿔 보여 줍니다.
- `updatedAt`이 화면의 `… 업데이트` 문구가 됩니다.
- `data.json`을 못 받아오면(오프라인·파일 직접 열기) `index.html` 안에 박아 둔 마지막 값(`DEFAULT_DATA`)으로 화면을 그립니다.

## 저장되는 것

서버로 보내는 데이터는 없습니다. 체크 상태·한마디·테마·좋아요·타자 기록은 그 태블릿 브라우저의 `localStorage`에만 남습니다.

- `familyBoard.todos.v1` — 알림장 체크(날짜가 바뀌면 초기화)
- `familyBoard.messages.v1` — 가족 한마디(최근 40개)
- `familyBoard.theme` — 라이트/다크 선택
- `familyBoard.favoriteMeals.v1` — 좋아하는 급식 메뉴(날짜·요일·메뉴·분류·시각 단위)
- `familyBoard.dictRecent.v1` — 최근 찾은 낱말 5개
- `familyBoard.savings.v1` — 은호 저축 목표 이름·목표 금액·모은 금액
- `familyBoard.typingBest.v1` — 오늘의 최고 타수 · `familyBoard.typingStreak.v1` — 연속 기록
- `familyBoard.bookReviews.v1` — 완독·별점·한 줄평(책장과 공유)

## 배포 방식

GitHub Pages가 **`gh-pages` 브랜치**를 보고 게시합니다 (`https://hamtole.github.io/family-dashboard/`).
그래서 내용을 고칠 때는 `main`에 커밋한 뒤 `gh-pages`에도 같이 올려 주세요.

```bash
git add -A && git commit -m "data.json 갱신: 11/18"
git push origin main
git push -f origin main:gh-pages
```

(`gh-pages`는 `main`을 그대로 밀어 넣는 방식이라 두 브랜치 내용이 같습니다.)

## 개인정보

이 저장소는 공개되어 있습니다. 그래서 성을 포함한 실명, 전화번호, 집 주소, 이메일, 학교명은 넣지 않았습니다. 학교 이름은 `학교점심`으로만 적고, 가족 호칭(아빠·엄마·은호)과 도시 단위 지역명만 씁니다.

전자사전에서 찾은 낱말은 뜻풀이를 받아 오기 위해 위키낱말사전(ko·simple·en)과 MyMemory 번역으로만 전송되고, 이름·기기 정보는 함께 보내지 않습니다. 저장되는 기록(최근 찾은 낱말·저축·완독·한마디·체크)은 모두 그 태블릿 브라우저의 `localStorage`에만 남습니다.
