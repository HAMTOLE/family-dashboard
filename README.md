# Family Dashboard

거실 태블릿에 띄워 두는 가족용 1페이지 대시보드입니다. 빌드 과정 없이 `index.html` 한 파일로 동작하며, GitHub Pages로 배포됩니다.

## 화면 구성 (3 × 2 여섯 칸)

| | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| **윗줄** | 📅 일정 | 🌦️ 날씨 / 🍱 학교점심 | 🏫 학교알림장 |
| **아랫줄** | 📰 어린이 뉴스 | ✏️ 오늘의 문제 | 👨‍👩‍👦 내 캐릭터 |

- **상단** — 실시간 시계·날짜, 🌙 다크모드(밤 8시~아침 7시 자동), ⛶ 전체화면
- **📅 일정** — `전체 / 아빠 / 엄마 / 은호` 필터를 누르면 그 사람 일정만 남습니다. 날짜·요일·오늘/내일 표시는 기기 시계로 계산합니다.
- **🌦️ 날씨 · 🍱 학교점심** — 한 칸 안에 위아래로 붙여 둔 카드. 날씨는 스냅샷 시각을 함께 적어 두었고, 급식은 샘플 메뉴입니다.
- **🏫 학교알림장** — 준비물·가정통신문 체크리스트. 누르면 완료 표시가 되고, 날이 바뀌면 체크가 새로 시작됩니다.
- **📰 어린이 뉴스** — 누르면 쉬운 설명이 펼쳐지는 아코디언 2건.
- **✏️ 오늘의 문제** — 초등 5~6학년 수학·논리 퀴즈 3문제. 보기를 누르면 바로 정답/해설이 나오고 `다음 문제`로 넘어갑니다.
- **👨‍👩‍👦 내 캐릭터** — 캐릭터를 누르면 한마디 입력창이 열리고, 보낸 글이 아래 `가족 한마디 보드`에 보낸 사람과 함께 쌓입니다.
- **하단 칩** — `📚 대출 중인 책 4권 (12/1 반납 · D-13)`. 누르면 책 목록이 열립니다.

## 저장되는 것

서버로 보내는 데이터는 없습니다. 체크 상태·한마디·테마는 그 태블릿 브라우저의 `localStorage`에만 남습니다.

- `familyBoard.todos.v1` — 알림장 체크(날짜가 바뀌면 초기화)
- `familyBoard.messages.v1` — 가족 한마디(최근 40개)
- `familyBoard.theme` — 라이트/다크 선택

## 고치고 싶을 때

`index.html` 아래쪽 `<script>` 안의 목록만 바꾸면 됩니다.

```js
// 일정 (who: dad / mom / kid)
var EVENTS = [
  { date: "2026-11-19", time: "11:00", title: "모두의 마당 모임", place: "코엑스", who: "mom" },
  ...
];

// 알림장 체크리스트
var TODOS = [ { id: "n1", text: "수학 익힘책 38~39쪽 풀어 오기" }, ... ];

// 오늘의 문제 (answer: 정답 보기의 순번, 0부터)
var QUIZ = [ { q: "문제", opts: ["①", "②", "③", "④"], answer: 0, why: "한 줄 해설" }, ... ];

// 대출 도서
var DUE = "2026-12-01";
var BOOKS = [ "책 제목", ... ];
```

날씨 문구와 급식 메뉴는 HTML의 `<!-- 2. 날씨 + 학교점심 -->` 블록에서 직접 고칩니다.

## 배포 방식

GitHub Pages가 **`gh-pages` 브랜치**를 보고 게시합니다 (`https://hamtole.github.io/family-dashboard/`).
그래서 내용을 고칠 때는 `main`에 커밋한 뒤 `gh-pages`에도 같이 올려 주세요.

```bash
git add -A && git commit -m "내용 수정"
git push origin main
git push -f origin main:gh-pages
```

(`gh-pages`는 `main`을 그대로 밀어 넣는 방식이라 두 브랜치 내용이 같습니다.)

## 개인정보

이 저장소는 공개되어 있습니다. 그래서 성을 포함한 실명, 전화번호, 집 주소, 이메일, 학교명은 넣지 않았습니다. 가족 호칭(아빠·엄마·은호)과 도시 단위 지역명만 씁니다.
