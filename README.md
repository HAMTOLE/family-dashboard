# Family Dashboard

거실 태블릿에 띄워 두는 가족용 1페이지 대시보드입니다. 빌드 과정 없이 `index.html` 한 파일로 동작하며, GitHub Pages로 배포됩니다.

## 보여 주는 것

- **상단** — 실시간 시계, 오늘 날짜(한국어 요일), 짧은 인사말
- **📚 대출 중인 책** — 반납 예정일까지 남은 날짜(D-day)를 기기 시계 기준으로 자동 계산
- **🗓️ 이번 주 주요 일정** — 날짜·시간·장소, 오늘/내일/모레 표시
- **✍️ 오늘의 좋은 문장** — 「공부를 하는 이유」 핵심 문장
- **⚡ 오늘의 한마디** — 자유 메모. 서버로 보내지 않고 그 기기 브라우저에만 저장됩니다.
- 🌙/☀️ 다크·라이트 전환, ⛶ 전체 화면 버튼

## 쓰는 법

1. 태블릿 브라우저에서 배포 주소를 연다.
2. 오른쪽 위 ⛶ 를 눌러 전체 화면으로 띄워 둔다.
3. 밤에는 🌙 로 다크 모드. 설정은 그 브라우저에 기억된다.

## 고치고 싶을 때

`index.html` 아래쪽 `<script>` 안의 두 목록만 바꾸면 됩니다.

```js
// 반납 예정일 (YYYY-MM-DD)
var DUE_DATE = "2026-12-01";
var BOOKS = [ { title: "책 제목" }, ... ];

// 일정
var EVENTS = [ { date: "2026-11-19", time: "11:00", title: "모임", place: "코엑스" }, ... ];
```

## 개인정보

이 저장소는 공개되어 있습니다. 그래서 실명, 전화번호, 집 주소, 이메일, 학교명 같은 개인정보는 넣지 않았습니다. 메모 카드의 내용도 서버가 아니라 태블릿 브라우저(localStorage)에만 남습니다.
