# Family Dashboard

거실 태블릿에 띄워 두는 가족용 1페이지 대시보드입니다. 빌드 과정 없이 `index.html` + `data.json` 두 파일로 동작하며, GitHub Pages로 배포됩니다.

디자인은 픽셀·레트로 톤입니다. 연한 민트그레이(`#E2EFEA`) 바탕에 도트 장식, 그 위에 웜크림(`#F8F5E6`) 패널, 카드는 순백 — 모든 테두리는 짙은 차콜(`#212529`) 2px 아웃라인에 하드 픽셀 그림자(`3px 3px 0`)를 씁니다. 포인트 컬러는 에메랄드 그린(완료·정답·진행), 코랄 레드(하트·마감 임박), 골드 옐로우(별점), 포켓몬 블루(책장·은호 공간·확인 버튼)입니다. 카드 헤더 아이콘·날씨·가족 아바타는 16×16 픽셀 SVG로 그렸고, 한글 본문은 Pretendard/시스템 고딕으로 읽기 쉽게 유지합니다. 다크 모드도 같은 픽셀 톤(짙은 민트 바탕 + 어두운 패널)으로 맞춥니다.

## 화면 구성 (3 × 2 여섯 칸)

| | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| **윗줄** | 📅 일정 | 🏫 학교알림장 & 🍱 학교점심 | 📚 대출 중인 책 |
| **아랫줄** | 📰 어린이 뉴스 | ✏️ 오늘의 문제 | 👨‍👩‍👦 내 캐릭터 |

- **상단** — 오늘 날짜와 실시간 시계, 그리고 오늘 날씨(파스텔 배지 안의 구름·해 그림 · 현재/최고/최저 기온 · 미세먼지 · 내일 추위 한 줄 · `11/18 10:45 업데이트`와 ­Weather 출처), 🚀 은호 공간, 🌙 다크모드(밤 8시~아침 7시 자동), ⛶ 전체화면. 1024×768 태블릿에서 스크롤 없이 한 화면에 들어갑니다.
- **📅 일정** — `전체 / 아빠 / 엄마 / 은호` 필터를 누르면 그 사람 일정만 남습니다. 날짜·요일·오늘/내일 표시는 기기 시계로 계산합니다.
- **🏫 학교알림장 & 🍱 학교점심** — 위에는 오늘의 알림장 체크리스트(누르면 완료, 날이 바뀌거나 알림장이 새로 오면 체크가 새로 시작), 아래에는 오늘 급식 메뉴가 2열 칩으로 나오고 **메뉴 하나하나 옆에 `🤍/❤️` 하트 버튼**이 붙습니다. 오른쪽 `❤️ 모음` 버튼은 지금까지 모은 메뉴 개수를 함께 보여 줍니다.
- **❤️ 맛있었던 메뉴 모음** — 메뉴 칩을 누르면 그 메뉴만 `❤️`로 바뀌며 `{날짜, 요일, 메뉴, 분류, 시각}`으로 저장됩니다. `❤️ 모음`을 누르면 좋아한 메뉴가 날짜별로 모인 팝업이 열리고(메뉴마다 분류 배지 · `✕`로 그 메뉴만 삭제), 예전에 하루 급식 전체를 저장하던 형식도 메뉴별로 펼쳐 읽습니다. 급식을 확인하지 못한 날은 메뉴 칩이 나오지 않습니다.
- **📚 대출 중인 책** — 반납일까지 남은 날(D-day)을 크게, 그 아래 대출 중인 책 목록. 책 제목을 누르면 완독·별점·한 줄평 팝업이 열립니다. 카드 헤더 오른쪽의 파스텔 `📖 책장 →` 버튼(태블릿에서 손가락으로 누르기 좋은 크기)을 누르면 **페이지를 옮기지 않고** 같은 화면 안에서 📚 은호의 책장 뷰로 바뀌므로, ⛶ 전체화면을 켠 채로도 전체화면이 풀리지 않습니다(`← 오늘 보드` 또는 Esc 로 복귀).
- **📰 어린이 뉴스** — 기사 줄을 누르면 대표 사진·쉬운 설명·생각해 볼 질문·출처가 담긴 팝업이 열립니다(배경 클릭·✕·`확인`으로 닫힘). 국내 소식 1건 + 과학·세계 소식 1건. 카드 안에는 제목과 분류 배지만 있어 3×2 배치가 흔들리지 않습니다.
- **✏️ 오늘의 문제** — 수학·과학·영어·국어를 고루 섞은 초등 5~6학년 문제 4개. 제목 옆 과목 배지가 붙고, 보기를 누르면 정답/해설이 나온 뒤 `다음 문제`로 넘어갑니다.
- **👨‍👩‍👦 내 캐릭터** — 캐릭터를 누르면 한마디 입력창이 열리고, 보낸 글이 아래 `가족 한마디 보드`에 보낸 사람과 함께 쌓입니다.

## 🚀 은호 공간 (`index.html#kids`)

은호가 안전하게 쓰는 네 칸짜리 공간입니다. 메인 헤더의 **`🚀 은호 공간`** 버튼(또는 주소 끝 `#kids`)으로 열리고, `← 오늘 보드`·Esc로 돌아옵니다. 책장과 마찬가지로 **페이지를 옮기지 않고 화면만 바뀌므로 ⛶ 전체화면이 풀리지 않습니다**.

- **📖 전자사전** — 큰 검색창에 낱말을 적고 `표준국어` / `네이버 국어` / `네이버 영어` 중 하나를 누르면 각 사전이 **새 창(팝업)** 으로 열립니다. 최근 찾은 낱말 5개는 칩으로 남아 다시 눌러 찾을 수 있습니다.
- **⌨️ 타자연습** — `한글 낱말` / `짧은 문장(속담·좋은 글)` / `영어 단어` 탭. 내장 게임이라 광고도, 바깥으로 나가는 링크도 없습니다. 입력하는 동안 글자마다 맞음/틀림이 색으로 표시되고 **타수(타/분)·정확도(%)·연속·오늘 최고 기록**이 함께 올라갑니다. `다음 문제 →` 또는 Enter로 다음 문제.
- **📺 오늘의 추천 영상** — EBS 5개 시리즈(지식채널e · 역사채널e · 3분 클립 과학 · 스쿨랜드 철학 · 헌법채널e)의 실제 유튜브 영상 2개씩. 카드를 누르면 `youtube-nocookie.com/embed/...?rel=0` 플레이어가 팝업으로 뜨고 **추천 영상·쇼츠·댓글 없는 화면**으로 재생됩니다. 영상이 안 열리는 환경을 위해 `YouTube에서 보기` 링크도 함께 둡니다.
- **📐 수학·과학 도구** — `알지오매스 키즈`, `Mathigon 폴리패드`, `PhET 초등 과학`을 팝업으로 열고, 아래에서 **분수 계산(약분·소수 표시)** 과 **단위 바꾸기(cm↔m↔km, g↔kg, mL↔L)** 를 바로 해 볼 수 있습니다.

## 📚 은호의 책장 (`index.html#shelf`)

`index.html` 안에 들어 있는 두 번째 화면입니다. `📖 책장 →` 로 열고 `← 오늘 보드`(또는 Esc)로 돌아오며, 페이지 이동이 아니라 화면 전환이라서 태블릿 전체화면이 그대로 유지됩니다. `index.html#shelf` 로 바로 열 수도 있고, 예전 주소 `bookshelf.html` 로 들어와도 이 화면으로 넘어옵니다.

- **제목**: `📚 은호의 책장` — 엄마 책은 넣지 않고 **은호 책만** 보여 줍니다(사람별 필터 없음).
- **상단 카운터 2개**: `🏅 올해 완독`(권수·최근 완독한 책) 과 `📖 현재 대출 중`(권수·`D-13`·반납 예정일).
- **📅 연도별 책장 탭**: 카운터 아래 `📅 2026년` `올해` 탭이 있고, **완독 기록이 있는 해마다 탭이 저절로 생깁니다**(올해 탭은 완독 0권이어도 항상 표시). 지난해 탭을 누르면 그 해에 다 읽은 책만 모아 보여 주고 `🏅 2026년 완독 N권`처럼 카운터도 그 해 기준으로 바뀝니다. 해가 바뀌면(예: 2027년) 새해 탭이 기본으로 열립니다.
- **맨 윗선반**: 지금 연도 탭에서만 `📖 지금 대출 중` 선반이 나오고, 각 책에 `대출 중 · D-13` 리본이 붙습니다. 지난 연도 탭에서는 대출 선반 없이 그 해 완독 책만 나옵니다.
- **그 아래 선반부터**: **다 읽은(완독) 책만** 읽은 순서대로 쌓입니다. 아직 안 읽은 희망 도서·미대출 책은 꽂지 않고, 완독이 0권이면 `다 읽은 책이 여기에 한 권씩 채워져요!` 안내가 나옵니다. 이미 완독한 책의 별점·한 줄평을 고쳐도 그 책은 처음 완독한 해에 그대로 남습니다.
- 책을 누르면 `다 읽었어요! (완독)` + ⭐별점 + 한 줄평을 저장할 수 있고, 저장하면 그 책이 아래 완독 선반에 꽂히며 `🏅 올해 완독` 숫자가 바로 올라갑니다. 대출 중인 책을 완독해도 반납 전까지는 윗선반에 `대출 중` 리본과 함께 남고, 완독 배지(✓·★)가 같이 붙습니다(아래 선반에는 `대출 중` 표시가 작게 붙습니다).
- 기록은 `localStorage` 키 `familyBoard.bookReviews.v1` 하나를 메인 보드와 함께 씁니다. 저장할 때 책 제목·저자·표지도 같이 남겨서, `data.json` 목록에 없는 책이라도 완독 선반에 표시됩니다.

## data.json — 매일 아침 자동 갱신되는 데이터

화면에 보이는 값은 모두 `data.json` 하나에서 옵니다. 페이지를 열 때 `./data.json?t=<현재시각>`으로 매번 새로 받아 그리므로, `data.json`만 고쳐 올리면 화면이 바뀝니다.

```json
{
  "updatedAt": "2026-11-18T10:05:00+09:00",
  "weather": { "place": "용인 · 수지구", "tempC": 6, "feelsC": 2, "condition": "흐림",
               "highC": 10, "lowC": 2, "wind": "북서풍 12km/h",
               "air": [ { "label": "미세먼지 좋음", "grade": "good" } ],
               "alert": "내일 아침 -2° … 목도리 챙기세요." },
  "lunch":   { "status": "ok", "note": "세계음식체험 · 인도 / 572 kcal", "menus": ["찹쌀밥", "마크니커리"] },
  "events":  [ { "date": "2026-11-19", "time": "11:00", "title": "모두의 마당 모임", "place": "코엑스", "who": "mom" } ],
  "notices": [ { "id": "n1", "text": "수학 익힘책 38~39쪽 풀어 오기" } ],
  "news":    [ { "tag": "사회", "title": "제목", "body": "쉬운 설명",
               "question": "생각해 볼 질문", "image": "https://…/대표사진.jpg", "source": "출처 (날짜)" } ],
  "quizzes": [ { "subject": "수학", "q": "문제", "opts": ["①", "②", "③", "④"], "answer": 0, "why": "한 줄 해설" } ],
  "books":   { "due": "2026-12-01", "items": ["책 제목", "..."] },
  "shelfBooks": [ { "id": "b5b110e", "title": "책 제목", "author": "저자", "who": "kid",
                    "status": "loan", "statusLabel": "대출 중", "cover": "covers/b5b110e.jpg",
                    "doneYear": "", "due": "2026-12-01" } ]
}
```

- `shelfBooks` — 책장에 쓰는 은호 책 목록입니다. `who`가 `mom`인 책은 책장에 나오지 않습니다. `status`가 `loan`인 책이 올해 탭의 윗선반(대출 중)에 꽂히고, 나머지는 완독 기록이 있을 때만 아래 선반에 꽂힙니다. 대출 중 책의 반납일은 `books.due`를 먼저 씁니다. `doneYear`(노션 `완독일`, 예: `"2026"` 또는 `"2026-05-03"`)가 있으면 그 해 책장에 꽂히고, 비어 있으면 앱에서 완독을 누른 날의 해를 씁니다.

- `who`는 `dad` / `mom` / `kid` 중 하나입니다. `answer`는 정답 보기의 순번(0부터)입니다.
- `quizzes[].subject`는 `수학` / `과학` / `영어` / `국어` — 화면 제목 옆 배지로 나오고 문제마다 색이 다릅니다.
- `news[].image`는 기사 팝업에 뜨는 대표 사진 URL입니다. 사진이 안 열리면 그 사진만 조용히 숨고 글은 그대로 보입니다(팝업 안에서 최대 높이만 제한).
- `lunch.status`가 `"ok"`가 아니거나 `menus`가 비어 있으면 화면에 `오늘 급식 정보 미확인`이 나옵니다. 확인하지 못한 날은 메뉴를 지어내지 말고 이 상태로 두세요.
- `weather.condition`은 한국어(`흐림`, `맑음`, `약한 비` …)로 적으면 그대로, 영어(`Cloudy`, `Drizzle` …)로 적으면 화면에서 한국어로 바꿔 보여 줍니다.
- `updatedAt`이 화면의 `… 업데이트` 문구가 됩니다.
- `data.json`을 못 받아오면(오프라인·파일 직접 열기) `index.html` 안에 박아 둔 마지막 값(`DEFAULT_DATA`)으로 화면을 그립니다.

## 저장되는 것

서버로 보내는 데이터는 없습니다. 체크 상태·한마디·테마·좋아요·타자 기록은 그 태블릿 브라우저의 `localStorage`에만 남습니다.

- `familyBoard.todos.v1` — 알림장 체크(날짜가 바뀌면 초기화)
- `familyBoard.messages.v1` — 가족 한마디(최근 40개)
- `familyBoard.theme` — 라이트/다크 선택
- `familyBoard.favoriteMeals.v1` — 좋아하는 급식 메뉴(날짜·요일·메뉴·분류·시각 단위)
- `familyBoard.dictRecent.v1` — 최근 찾은 낱말 5개
- `familyBoard.typingBest.v1` — 오늘의 최고 타수 · `familyBoard.typingStreak.v1` — 연속 기록
- `familyBoard.bookReviews.v1` — 완독·별점·한 줄평(책장과 공유)

## 배포 방식

GitHub Pages가 **`gh-pages` 브랜치**를 보고 게시합니다 (`https://hamtole.github.io/family-dashboard/`).
그래서 내용을 고칠 때는 `main`에 커밋한 뒤 `gh-pages`에도 같이 올려 주세요.

```bash
git add -A && git commit -m "data.json 갱신: 11/18"
git push origin main
git push -f origin main:gh-pages
```

(`gh-pages`는 `main`을 그대로 밀어 넣는 방식이라 두 브랜치 내용이 같습니다.)

## 개인정보

이 저장소는 공개되어 있습니다. 그래서 성을 포함한 실명, 전화번호, 집 주소, 이메일, 학교명은 넣지 않았습니다. 학교 이름은 `학교점심`으로만 적고, 가족 호칭(아빠·엄마·은호)과 도시 단위 지역명만 씁니다.
