# Family Dashboard

거실 태블릿에 띄워 두는 가족용 1페이지 대시보드입니다. 빌드 과정 없이 `index.html` + `data.json` 두 파일로 동작하며, GitHub Pages로 배포됩니다.

## 화면 구성 (3 × 2 여섯 칸)

| | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| **윗줄** | 📅 일정 | 🏫 학교알림장 & 🍱 학교점심 | 📚 대출 중인 책 |
| **아랫줄** | 📰 어린이 뉴스 | ✏️ 오늘의 문제 | 👨‍👩‍👦 내 캐릭터 |

- **상단** — 오늘 날짜와 실시간 시계, 그리고 오늘 날씨(큰 날씨 그림 · 현재/최고/최저 기온 · 미세먼지 · 내일 추위 한 줄 · `11/18 10:45 업데이트`와 ­Weather 출처), 🌙 다크모드(밤 8시~아침 7시 자동), ⛶ 전체화면. 1024×768 태블릿에서 스크롤 없이 한 화면에 들어갑니다.
- **📅 일정** — `전체 / 아빠 / 엄마 / 은호` 필터를 누르면 그 사람 일정만 남습니다. 날짜·요일·오늘/내일 표시는 기기 시계로 계산합니다.
- **🏫 학교알림장 & 🍱 학교점심** — 위에는 오늘의 알림장 체크리스트(누르면 완료, 날이 바뀌거나 알림장이 새로 오면 체크가 새로 시작), 아래에는 오늘 급식 메뉴.
- **📚 대출 중인 책** — 반납일까지 남은 날(D-day)을 크게, 그 아래 대출 중인 책 목록.
- **📰 어린이 뉴스** — 누르면 대표 사진과 쉬운 설명이 펼쳐지는 아코디언. 국내 소식 1건 + 과학·세계 소식 1건.
- **✏️ 오늘의 문제** — 수학·과학·영어·국어를 고루 섞은 초등 5~6학년 문제 4개. 제목 옆 과목 배지가 붙고, 보기를 누르면 정답/해설이 나온 뒤 `다음 문제`로 넘어갑니다.
- **👨‍👩‍👦 내 캐릭터** — 캐릭터를 누르면 한마디 입력창이 열리고, 보낸 글이 아래 `가족 한마디 보드`에 보낸 사람과 함께 쌓입니다.

## data.json — 매일 아침 자동 갱신되는 데이터

화면에 보이는 값은 모두 `data.json` 하나에서 옵니다. 페이지를 열 때 `./data.json?t=<현재시각>`으로 매번 새로 받아 그리므로, `data.json`만 고쳐 올리면 화면이 바뀝니다.

```json
{
  "updatedAt": "2026-11-18T10:05:00+09:00",
  "weather": { "place": "용인 · 수지구", "tempC": 6, "feelsC": 2, "condition": "흐림",
               "highC": 10, "lowC": 2, "wind": "북서풍 12km/h",
               "air": [ { "label": "미세먼지 좋음", "grade": "good" } ],
               "alert": "내일 아침 -2° … 목도리 챙기세요." },
  "lunch":   { "status": "ok", "note": "세계음식체험 · 인도 / 572 kcal", "menus": ["찹쌀밥", "마크니커리"] },
  "events":  [ { "date": "2026-11-19", "time": "11:00", "title": "모두의 마당 모임", "place": "코엑스", "who": "mom" } ],
  "notices": [ { "id": "n1", "text": "수학 익힘책 38~39쪽 풀어 오기" } ],
  "news":    [ { "tag": "사회", "title": "제목", "body": "쉬운 설명",
               "question": "생각해 볼 질문", "image": "https://…/대표사진.jpg", "source": "출처 (날짜)" } ],
  "quizzes": [ { "subject": "수학", "q": "문제", "opts": ["①", "②", "③", "④"], "answer": 0, "why": "한 줄 해설" } ],
  "books":   { "due": "2026-12-01", "items": ["책 제목", "..."] }
}
```

- `who`는 `dad` / `mom` / `kid` 중 하나입니다. `answer`는 정답 보기의 순번(0부터)입니다.
- `quizzes[].subject`는 `수학` / `과학` / `영어` / `국어` — 화면 제목 옆 배지로 나오고 문제마다 색이 다릅니다.
- `news[].image`는 기사 대표 사진 URL입니다. 사진이 안 열리면 그 사진만 조용히 숨고 글은 그대로 보입니다(높이는 카드에 맞게 잘라 표시).
- `lunch.status`가 `"ok"`가 아니거나 `menus`가 비어 있으면 화면에 `오늘 급식 정보 미확인`이 나옵니다. 확인하지 못한 날은 메뉴를 지어내지 말고 이 상태로 두세요.
- `weather.condition`은 한국어(`흐림`, `맑음`, `약한 비` …)로 적으면 그대로, 영어(`Cloudy`, `Drizzle` …)로 적으면 화면에서 한국어로 바꿔 보여 줍니다.
- `updatedAt`이 화면의 `… 업데이트` 문구가 됩니다.
- `data.json`을 못 받아오면(오프라인·파일 직접 열기) `index.html` 안에 박아 둔 마지막 값(`DEFAULT_DATA`)으로 화면을 그립니다.

## 저장되는 것

서버로 보내는 데이터는 없습니다. 체크 상태·한마디·테마는 그 태블릿 브라우저의 `localStorage`에만 남습니다.

- `familyBoard.todos.v1` — 알림장 체크(날짜가 바뀌면 초기화)
- `familyBoard.messages.v1` — 가족 한마디(최근 40개)
- `familyBoard.theme` — 라이트/다크 선택

## 배포 방식

GitHub Pages가 **`gh-pages` 브랜치**를 보고 게시합니다 (`https://hamtole.github.io/family-dashboard/`).
그래서 내용을 고칠 때는 `main`에 커밋한 뒤 `gh-pages`에도 같이 올려 주세요.

```bash
git add -A && git commit -m "data.json 갱신: 11/18"
git push origin main
git push -f origin main:gh-pages
```

(`gh-pages`는 `main`을 그대로 밀어 넣는 방식이라 두 브랜치 내용이 같습니다.)

## 개인정보

이 저장소는 공개되어 있습니다. 그래서 성을 포함한 실명, 전화번호, 집 주소, 이메일, 학교명은 넣지 않았습니다. 학교 이름은 `학교점심`으로만 적고, 가족 호칭(아빠·엄마·은호)과 도시 단위 지역명만 씁니다.
